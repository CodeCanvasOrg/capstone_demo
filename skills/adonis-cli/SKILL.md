# AdonisJS CLI (ace) for capstone_demo

## Golden rule

**Never hand-create a framework file.** Every AdonisJS scaffold — controller, model,
migration, validator, transformer, policy, service, middleware, command, seeder, factory,
test, Inertia page — is generated by `node ace`. Hand-written scaffolds drift from the
framework's stubs and break codegen.

```bash
node ace <command>          # always `node ace`, never `npx ace` or a global install
node ace <command> --help   # flags for the installed version (source of truth, not docs)
```

Check `node ace list --json` for what this repo actually has. Installed generators are
from `@adonisjs/core`, `@adonisjs/lucid`, `@adonisjs/session`, `@adonisjs/inertia`, and
`@adonisjs/bouncer` (see `adonisrc.ts` → `commands`). Anything not listed is not
installed — install the package first (below).

> Docs drift from the installed version. `node ace <cmd> --help` is authoritative.

## Adding a package

```bash
node ace add @adonisjs/queue --package-manager npm
```

`ace add` runs install **and** the package's configure hook (writes config file, appends
the provider to `adonisrc.ts`). Never `npm install` a package by hand and then hand-edit
`adonisrc.ts`. Shorthands work: `node ace add vinejs`, `node ace add edge`.

## Generator reference for this repo

| Need | Command | Output |
|---|---|---|
| CRUD controller | `node ace make:controller --resource documents` | `app/controllers/documents_controller.ts` |
| Singular controller | `node ace make:controller --singular session` | `app/controllers/session_controller.ts` |
| JSON-only API controller | `node ace make:controller --api --resource widgets` | no `create`/`edit` |
| Custom actions | `node ace make:controller documents export publish` | only those methods |
| Business logic | `node ace make:service documents/exports` | `app/services/documents/exports.ts` |
| Model + migration + factory | `node ace make:model Document -mf` | model, migration, factory |
| Transformer | `node ace make:transformer document` | `app/transformers/document_transformer.ts` |
| Migration | `node ace make:migration add_status_to_documents` | `database/migrations/*` |
| Alter table | `node ace make:migration alter_documents_status --alter` | `schema.alterTable(...)` |
| Validator | `node ace make:validator document --resource` | `app/validators/document.ts` |
| Bouncer policy | `node ace make:policy document edit update delete` | `app/policies/document_policy.ts` |
| Middleware (+ register) | `node ace make:middleware authenticate --stack=router` | file **and** `start/kernel.ts` edit |
| Ace command | `node ace make:command sync_documents` | `commands/sync_documents.ts` |
| Seeder | `node ace make:seeder Document` | `database/seeders/*` |
| Factory | `node ace make:factory Document` | `database/factories/*` |
| Inertia page | `node ace make:page documents/show --react` | `inertia/pages/documents/show.tsx` |
| Test | `node ace make:test documents --suite=functional` | `tests/functional/documents.spec.ts` |
| Custom exception | `node ace make:exception EmbeddingFailure` | `app/exceptions/*` |
| Event / listener | `node ace make:event DocumentIndexed` + `node ace make:listener index_document -e DocumentIndexed` | event + bound listener |

Existing naming proves the convention: **plural resource controllers**
(`documents_controller.ts`), **singular domain services** (`files_service.ts`),
**singular models and transformers**, **plural validator files** (`documents.ts`).

`--force` overwrites an existing file. Never pass it on a file you did not intend to
replace.

## Wiring commands that change files

Run these after generators, before typechecking:

```bash
node ace codegen        # regenerates #generated/* (controllers, routes, entities, policies)
node ace list:routes --jsonl   # flat JSONL, one route per line — best for agents
node ace generate:key  # new APP_KEY (never commit the output)
```

`node ace codegen` is what makes `#generated/controllers`, `#models/*`,
`#transformers/*` importable. A "cannot find module `#generated/...`" error means you
skipped it.

## Database

```bash
node ace migration:run
node ace migration:status
node ace migration:fresh --seed     # drop all + run + seed (destructive)
node ace migration:rollback
node ace db:seed
node ace schema:dump                # update SchemaEZ snapshot after schema changes
```

Connection is `pg` via `DB_URL` (`config/database.ts`). Migrations live in
`database/migrations` with `naturalSort: true`.

## Day-to-day

```bash
npm run dev         # node ace serve --hmr
npm test            # node ace test
npm run build       # node ace build
npm run lint
npm run typecheck   # tsc --noEmit && tsc --noEmit --project inertia/tsconfig.json
./bin/run-dev.sh    # installs Bun if missing, bun install, bun run dev
```

## After every ace change

```bash
node ace codegen && npm run typecheck && npm run lint
```

## Traps seen in this repo

- `make:model` declares `-c, --controller` and `-c, --transformer` — the two short flags
  collide. Use the long form (`--controller`, `--transformer`).
- `list:routes --json` is nested; `--jsonl` is one route per line and far easier to read.
- Custom route names come from `.as('files')` / `.as('documentVersions.store')` in
  `start/routes.ts` — check `node ace list:routes` before assuming a name.
- Controllers are registered from `commands/` automatically; packages must be listed in
  `adonisrc.ts` → `commands` to contribute their own.
